# Línea del Tiempo Musical

Juego musical estilo "adivina el año" para jugar en grupo, cada uno desde su celular.

- Página: https://osobatteryia.github.io/linea-del-tiempo/
- El anfitrión crea la sala y conecta su Spotify Premium; los demás entran con el QR o el código, sin cuentas.
- La sincronización usa un broker MQTT público (mensaje retenido por sala).
